## 1. 装两个小工具

打开 **命令提示符**（按 `Win` 键，输入 `cmd`，回车），然后敲：

```bat
git --version
uv --version
```

**你应该看到**：两行版本号。

- `git` 那行报「不是内部或外部命令」→ 去 <https://git-scm.com/download/win> 装，装完**关掉这个黑窗口重新开一个**（不然它不认新装的命令）。
- `uv` 那行报错 → 敲这一条装它：

```bat
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

装完**一样要关掉黑窗口重开**。

> **为什么用 uv**：它是一个"自带 Python 环境管理"的工具。装了它就不用自己装 Python、也不用自己建虚拟环境。

**另外确认一件事**：你的电脑上**装了 QQ 并且登录过**。VIGIL 要读 QQ 的本地数据库，没登录过就读不到东西。

## 2. 拿密钥（这步最麻烦）

### 先说清楚这是什么东西

要读 QQ 的数据库，得先有一个 **16 字节的解密密钥**。这个密钥：

- **只存在于你的电脑上**，由你的 QQ 在运行时算出来；
- 腾讯**不提供**任何接口让你取它；
- 所以**任何仓库、任何网站都给不了你**，只能用一个"调试器脚本"从你自己的 QQ 里把它读出来。

这就是整件事**唯一的门槛**。如果你觉得"用调试器"这几个字很吓人——**它是真的有点门槛**，别自我怀疑。

### 怎么做

**完整步骤在另一份文档里**，那份写得比我这里细，还有风险说明和出问题时的退路：

> ## 👉 打开 [`docs/SETUP-密钥提取.md`](SETUP-密钥提取.md) 照着做

⚠️ **动手前务必看一眼那份文档开头的「风险知情」**：那个脚本属于注入式操作，
上游明确警告**可能破坏聊天记录、也可能导致 QQ 封号**。文档第 0 步就是教你备份。

**做完这一步，你应该得到**：一串 16 字节的密钥（看着像乱码）。**先抄在记事本里备用。**

> **如果你在这里卡死了**：那份文档最后有「走不通时的替代方案」——包括去看上游的完整教程
> 仓库、换台虚拟机重试、或者干脆放弃 VIGIL 的自动化路线。这不丢人，那一步本来就不是
> 给所有人设计的。

## 3. 下载 VIGIL 并装依赖

```bat
cd /d C:\Users\nebul\Downloads
git clone https://github.com/f25h-233/vigil.git vigil
cd vigil
uv sync
```

**你应该看到**：`git clone` 很快结束；`uv sync` 下载一堆依赖，最后类似 `Installed N packages`。

> 路径 `C:\Users\nebul\Downloads` 换成你自己想放的地方。
> **整个项目就在这个 `vigil` 文件夹里**，以后所有命令都要先 `cd` 到这里。

---

## 4. 填 .env

```bat
copy .env.example .env
notepad .env
```

记事本会弹出来。你会看到两行要填：

```ini
VIGIL_DB_KEY=
SILICONFLOW_API_KEY=
```

- `VIGIL_DB_KEY=` 后面 → 填**第 2 步抄下来的那 16 字节密钥**
- `SILICONFLOW_API_KEY=` 后面 → 去 <https://cloud.siliconflow.cn/account/ak> 申请一个（注册后点几下就有，几分钟）

存盘、关掉记事本。

> ⚠️ **别改左边的名字**。特别是别写成 `NTQQ_DB_KEY`——那是旧文档里的错名字，代码不认。

---

## 5. 验证密钥有没有抄对

先做一个**占位配置文件**（第 6 步才会真正填它）：

```bat
copy config\groups.example.toml config\groups.toml
```

然后：

```bat
uv run vigil groups
```

**你应该看到**：一长串群号和群名，像这样：

```
★         52,341  2026-10-18  615935556   某某班级群
          8,102   2026-10-17  869354355   某某二手群
...
共 27 个群有消息记录，已纳入 0 个
```

看到这个 ⇒ **密钥是对的，最难的关过了。** 🎉

| 如果你看到 | 说明 | 怎么办 |
|---|---|---|
| `无法解密，密钥可能不对` | 密钥抄错了 | 回第 2 步重抄。16 字节，**一个字符都不能差** |
| `没有数据库密钥` | `.env` 没被读到 / 名字写错 | 回第 4 步，确认文件名是 `.env`（不是 `.env.txt`）、变量名是 `VIGIL_DB_KEY` |
| `找不到配置文件` | 漏了上面那条 `copy` | 补上 |
| `QQ 数据库目录不存在` | 路径不对或 QQ 没登录过 | 检查 QQ 数据目录，见[卡住了怎么办](#卡住了怎么办) |

## 6. 告诉 VIGIL 盯哪些群

```bat
notepad config\groups.toml
```

文件里有一段 `[[groups]]` 的示例。把**第 5 步列出来的群号**，照格式改成你真正想盯的群：
每个群一段，填 `id`（群号）和 `name`（你随便起的名）。

存盘、关掉。再跑一次确认没写坏：

```bat
uv run vigil groups
```

这次已纳入的群前面会有 `★`。

---

## 7. 跑一次，把数据产出来

```bat
uv run vigil daily
```

**你应该看到**：一串进度（导出多少条消息、抽取多少条、生成日报）。会跑一会儿。

跑完，`data\vigil.db` 就存在了——**网页读的就是它**。没跑过这步，网页是空的。

> 以后想让它每天自动跑，见 [`SETUP-自动化.md`](SETUP-自动化.md)（任务计划）。先用不着。

## 8. 补前端

`git clone` 下来的东西**不含网页界面**（构建产物不入库，这是个规矩）。不补的话，网页只会显示一行「前端尚未构建」。

1. 打开 <https://github.com/f25h-233/vigil/releases/tag/v2.63.130a>
2. 下载附件 **`vigil-web-dist-2.63.130a.tar.gz`**
3. 解压它，里面有个 `web\dist\` 文件夹
4. **把整个 `dist` 文件夹**放到你项目里的 `vigil\web\` 下

**确认**：`...\vigil\web\dist\index.html` 这个文件存在。

> 不想手动弄？也可以在 `vigil\web` 目录下自己构建（需要装 Node.js）：
> ```bat
> cd web
> npm install
> npm run build
> ```

## 9. 启动，看网页

```bat
cd /d C:\Users\nebul\Downloads\vigil
run.cmd
```

（**也可以直接在资源管理器里双击 `run.cmd`**。）

**你应该看到**：黑窗口里逐条打出

```
[1/5] .env 已就绪（两个 key 都已填写）。
[2/5] config/groups.toml 在。
[3/5] 数据在（...\data\vigil.db）。
[4/5] 端口 8787 空闲。
[5/5] 前端已构建。
  启动中：http://127.0.0.1:8787
```

然后**浏览器自动打开**，出现 VIGIL 的界面。

**完事了。** 关掉黑窗口就是停止服务。

## 卡住了怎么办

### `run.cmd` 报某个步骤没过

它**会告诉你缺哪一步、去做什么**——照着那句提示走就行。它拦下的每一种情况都对应上面某一节：

| `run.cmd` 说 | 回到哪一节 |
|---|---|
| `[1/5] 还没建 .env` / `有 key 还没填` | [第 4 步](#4-填-env) |
| `[2/5] 还没有 config/groups.toml` | [第 6 步](#6-告诉-vigil-盯哪些群) |
| `[3/5] 还没有数据` | [第 7 步](#7-跑一次把数据产出来) |
| `[4/5] 端口已被占用` | 见下 |
| `[5/5] 前端还没构建` | [第 8 步](#8-补前端)（不致命，服务照起） |

### 端口被占

多半是 **VIGIL 已经在跑了**（另一个窗口没关）。直接开 <http://127.0.0.1:8787> 看看；想再起一个就 `run.cmd --port 8899`（不加它也会自动换端口）。

### `QQ 数据库目录不存在`

VIGIL 默认按这个路径找你的 QQ 数据：

```
C:\Users\<你的用户名>\Documents\Tencent Files\<你的QQ号>\nt_qq\nt_db
```

去资源管理器确认这个目录在不在。QQ 装在别处、或数据目录被改过的话，你需要在
`config\groups.toml` 的 `[settings]` 里写对 `qq_db_dir`。

### 密钥那一步彻底做不下去

见 [`SETUP-密钥提取.md`](SETUP-密钥提取.md) 最后的「走不通时的替代方案」。里面也说了
如果不走密钥路线、单纯想备份聊天记录该怎么用 QQ 自带功能。

### 还是不行

把**完整的错误信息**（别只贴最后一行）连同你敲的命令一起发出来。黑窗口里可以
右键 → 标记 → 拖选 → 回车复制。

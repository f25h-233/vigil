## ⭐ M2 最重要的一条设计判断：**只说自己有资格说的话**

这个里程碑真正的工作，不是让日报**写得好看**，而是让它**说话算数**。
实测抓出「日报说了一句可能是假的话」的**五个变体**：

| # | 那句话 | 什么情况下是假话 |
|---|---|---|
| 1 | 「没有值得一提的信息」 | 抽取**没跑**时 |
| 2 | 同上 | **没导出数据**时 |
| 3 | 「N 条筛掉…M 条送模型」 | 退化输入下打印退化句子 |
| 4 | 「当天 N 条消息，提炼出 M 条」 | **只抽取了一部分**时，读起来像读遍了全部 |
| 5 | **`--dry-run` 的预览** | 预览描述的是「日报会说什么」，正文改了它就成了假话 |

**共同结构**：日报每说一句**关于完整性**的话，都必须先核**自己有没有资格说这句**。

**可推广的判据**：
> 1. **凡是隐含「这就是全部」的表述，都要先做覆盖核验。**
> 2. **能推导的，不要重述**（derive, don't restate）——重述的地方每个人都会忘。
>    （第 5 个变体的修法就是这条：让预览**引用**实际正文，而不是另写一句。）

## 已知缺陷（**带着走，别当它完美**）

1. **`items.deadline_ts` 半数不可信**（见上，**M3 必读**）
2. **M1 补出的日期在正文里仍可见**：9/13「课程安排：第五周开课」正文的「今日（9月14日）」，
   源文只有「今天上午有一节课第五周开」。它**不带 `· 截止 ·` 戳、不在「别忘」里**，
   但确实是无依据的日期——**走的不是 deadline 路径，所以这轮核验管不到**
3. **`vigil refine` 仍有全角引号退化隐患**：全库 **25 条**消息含 `“ ”`，会让模型退化成
   无限空格循环。M2 只在日报载荷侧修了（`sanitize_for_llm`），**refine 侧未修**——
   改它等于改 M1 已验证的提示词输入，会牵出 prompt_ver 升版与出口核验重跑
4. **`refine.py` 日志与日报同名不同义**：日志「本地丢弃 83」只算**硬丢弃**，
   日报「本地筛掉 1,014」含「没命中保留规则」——**差 12 倍**，对照会被误导
5. **`PROMPT_VERSION` 的 payload 侧无自动守卫**：指纹只覆盖 `build_system_prompt`，
   改 `build_user_prompt`/`build_items_payload` 的字段集不会被测试拦下
6. **汉字日期写法无数字边界**：`1月6日` 会在 `11月6日` 里命中（**改前就有**）；
   点号写法引入新假阳性面（全库 87 处 `M.D` token，今天 0 现形）
7. **Task 12 的覆盖率分支今天不可达**：51 个有数据的日子覆盖率**全 100%**，
   那条限定是 **M4 才会唤醒**的
8. **日报措辞不可复现**：结构幂等 ≠ 字节幂等（temperature 0.1 ≠ 0）。
   **不能用 sha256 证明「LLM 产物没被改动」**

## SDD 执行方式（**M3 直接沿用**）

- **模式：pipeline**。M1 上 wave 吃过亏（任务粒度太小），M2 全程 pipeline，24 个 commit 当天闭环。
- 每任务 = brief → implementer → 审查 → 裁决 → fix → **scoped re-review**。
- **派发时必带**（本轮血泪，逐条都是真金）：
  1. **变异反证必须加阳性对照**，否则「全红」不可信
  2. **跑测前清 `__pycache__` + `PYTHONDONTWRITEBYTECODE=1`**——`.pyc` 只按 `(mtime 秒, 大小)` 校验，
     同尺寸变异同秒写入会**复用旧字节码**（本轮两次假红/假 CAUGHT 都源于此）
  3. **隔离副本要用 `git -c core.autocrlf=false -c core.eol=lf archive`**——默认产出 CRLF，不是被审字节
  4. **副本里先自检 `vigil.__file__` 指向副本**——editable finder 会把 `vigil` 硬映射到工作区，
     不自检则**副本里所有变异都会「存活」**（全套假阴性）
  5. **变异锚点写成脚本文件、不走命令行传**——Git Bash 向原生 python 传非 ASCII 参数会被**静默打空**
  6. **锚点必须全局唯一**，并断言命中次数 ≥1（本轮拦下过两次双命中/零命中事故）
  7. **不要在共享工作区里做变异**——会污染并发的其它 agent（本轮实测到过）
  8. **禁止在真库真窗口重跑已验收产物**——重跑会不可逆地刷新 `created_at`/`digest_id`，
     且 hash 必变。证明 LLM 产物未变只能用**隔离副本 + 冻结模型 A/B**
  9. **文件级 `git add`**，提交后 `git show --stat` 自查——`git add -A` 会卷入同事的未提交改动
  10. **agent 断线后先查仓库再决定**，不靠自述（本轮省掉过一轮重派）
